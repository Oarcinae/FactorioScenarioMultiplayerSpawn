# Oarc Classic
A Factorio mod for separate spawn locations in multiplayer, built on vanilla starting areas. Designed for Co-op and PvE.

Every planet gets a fixed grid of starting points when the game starts. Each new player takes the next free point, spiralling out from the center, and gets a normal vanilla starting area there. Players can also join someone else's spawn.

Oarc Classic is a stripped down version of [Oarc Multiplayer Spawn](https://mods.factorio.com/mod/oarc-mod). The two mods can't be enabled together.

## Versions
1.0.X supports Factorio V2.1 with and without the Space Age expansion.
